# dotfiles

Configuration for one Arch Linux laptop, laid out as GNU stow packages. Enough of
it is here to rebuild the machine from a fresh install.

**[MACHINE.md](MACHINE.md)** — what the hardware is, how the session is put
together, and the bugs this configuration works around. Read it before installing
anywhere that is not the same laptop.

**[INSTALL.md](INSTALL.md)** — the procedure, in order, from `iwctl` to a working
desktop.

## Layout

Every top-level directory except `system/` is a stow package mirroring the path
under `$HOME`:

```
waybar/.config/waybar/style.css   ->   ~/.config/waybar/style.css
```

```bash
cd ~/dotfiles && stow -t ~ waybar          # one package
cd ~/dotfiles && stow -t ~ */              # everything
```

| | |
|---|---|
| `hyprland` `hyprlock` `hyprpaper` `hyprmocha` | compositor, lock screen, wallpaper, theme |
| `waybar` `wofi` | status bar and launcher |
| `kitty` `nvim` `tmux` `starship` `zshrc` | terminal and shell |
| `chrome` `spotify` | Wayland flags for two stubborn apps |
| `backgrounds` | wallpapers |
| `local-bin` | scripts in `~/.local/bin` |
| `systemd-user` | user units |
| `wireplumber` | audio drop-in that protects the tuned mic gain |
| `system` | **not a stow package** — root-owned `/etc` files plus `install.sh` |
| `pkglist-repo.txt` `pkglist-aur.txt` | `pacman -Qqe` and `-Qqm`, regenerated by hand |

## Not in here

Credentials, by design, since this repository is public: `~/.config/secrets.env`,
`/etc/sing-box/config.json`, the NetworkManager profiles with their plaintext PSKs,
and `~/.local/bin/connectvm`. `.gitignore` blocks all four by path. INSTALL.md
step 7 lists where each one lives and how to carry it across.

## Checking for drift

`system/` holds copies of root-owned files, and copies go stale. This compares them
against the live system without writing anything:

```bash
sudo bash system/install.sh --dry-run
```
